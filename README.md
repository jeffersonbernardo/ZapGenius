# ZapGenius

Bot para WhatsApp com foco em criação de figurinhas, assistência com IA e ferramentas de administração de grupos.

## Objetivos

- Criar figurinhas a partir de imagens e mídias compatíveis.
- Oferecer comandos inteligentes com apoio de IA.
- Disponibilizar recursos de organização e administração de grupos.

## Status

🚧 Em desenvolvimento.

A compatibilidade com recursos específicos do WhatsApp, incluindo figurinhas com áudio e automação em grupos, será validada antes da implementação.

## Segurança

- Não armazene tokens, senhas ou credenciais neste repositório.
- Use variáveis de ambiente para configurações privadas.
